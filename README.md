# Šarados

Mobile-first lietuviškų šaradų prototipas viename telefone.

## Paleidimas

```bash
npm install
npm run dev
```

Atidarykite `http://localhost:3000`.

## Patikra

```bash
npm run lint
npm run typecheck
npm test
```

Žaidimas veikia tik naršyklės atmintyje: nėra paskyrų, API, duomenų bazės ar nuolatinio saugojimo.
